Public reachability

Tell off-site viewers how to reach this station. The hostname is also the Let's Encrypt certificate name. Leave both blank for LAN-only. IT still needs to forward ports 8889 and 8189 to this box. Test checks DNS and this box's WAN IP; port probes from here can fail even when off-site works. Test never blocks Save. Saving reconnects viewers; live encodes keep running.

Cloudflare TURN

Optional relay for viewers who cannot reach this station on port 8189 (hotel Wi-Fi, some cellular, locked-down offices). Direct 8189 is still preferred when it works. Does not replace Public hostname or the firewall forwards. Create a TURN key under Cloudflare Realtime, then paste the key ID and API token here. Stored in the auth database — never in a channel or station .env.

Cloudflare Stream

Offload viewer fan-out so this box's 1 Gb NIC is not multiplied. The station WHIPs each live path once to Cloudflare Stream; those viewers WHEP from Stream. Hybrid keeps logged-in Player / Multiview on local MediaMTX (LAN latency, Kick/Metrics still work). Share links and the portal use Stream. All viewers sends everyone to Stream. TURN (above) is a connectivity relay and does not replace this. Stored in the auth database — never a .env.
